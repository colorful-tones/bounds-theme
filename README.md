# Bounds - WordPress theme for Presentations / Slidedecks

[Bounds theme on WordPress.org](https://wordpress.org/themes/bounds/)

## Acknowledgements

Lots of inspiration from many different projects and contributors in the WordPress community, including:

- Ryan Welcher's continuous community training for all things block related and the Interactivity API. His [Presentation plugin](https://github.com/ryanwelcher/presentation) played a critical role.
- The [Stack theme](https://wordpress.org/themes/stacks/), which pioneered the idea of a WordPress theme for presentations.
- The amazing Interactivity API contributors (creators, documentation and so much more).
